# Как собрать MSI-пакет для Агента Инвентаризации

Чтобы получить файл `.msi` из файла `agent_collector.ps1` для твоей дипломной работы, используй один из этих проверенных методов:

### Метод 1: Advanced Installer (Лучший визуальный способ)
1. Скачай **Advanced Installer** (есть бесплатная версия).
2. Выбери проект **"Installer"**.
3. В разделе **Files and Folders** добавь файл `agent_collector.ps1`.
4. В разделе **Prerequisites** (или Custom Actions) укажи запуск PowerShell:
   - Команда: `powershell.exe -ExecutionPolicy Bypass -File "[#agent_collector.ps1]"`
5. Нажми **Build** — на выходе получишь готовый `.msi`.

### Метод 2: MSI Wrapper (Рекомендуется для HSA)
1. Скачай утилиту **MSI Wrapper**.
2. Выбери запускной файл (цель: `hsa_agent.exe`, полученный через `ps2exe`).
3. Заполни метаданные (название: HSA Agent, версия: 1.0.4, разработчик: Комиссаров Кирилл Александрович).
4. **Тихая установка:** MSI автоматически поддерживает передачу параметров. Если запустить установку так:
   `msiexec /i HSA_Agent.msi /qn` — установка пройдет скрыто.
   Благодаря новой логике скрипта, при первом запуске после тихой установки он один раз спросит сервер у пользователя.

Если вы хотите **полностью автоматизировать** ввод сервера при установке, лучше всего сконфигурировать MSI так, чтобы он создавал файл `%APPDATA%\HSA_Agent\config.json` с нужным URL.

### Метод 3: WiX Toolset (Хардкорный путь для программиста)
Если в дипломе нужно показать "сложный" путь:
1. Опиши структуру пакета в `.wxs` (XML-файл).
2. Используй компилятор `candle.exe` и линковщик `light.exe`.
3. Это выглядит очень солидно для комиссии!

### Метод 4: Удаленное управление (VNC/RDP)
Для реализации функции "подключиться к ПК" в твоем проекте используется связка:
1. **На стороне клиента (MSI):** Пакет должен устанавливать не только наш скрипт, но и VNC-сервер (например, **UltraVNC** или **TightVNC**) в режиме службы (Service Mode).
   - В скрипт `agent_collector.ps1` добавлена проверка статуса VNC.
2. **На стороне администратора (Веб-интерфейс):** Кнопка "Управление" в веб-панели использует протокол `vnc://[IP]`.
   - Администратору нужно установить любой VNC Viewer (клиент). При клике в браузере, система предложит открыть установленный клиент.

---
**Совет для диплома:** Упомяни, что использование MSI позволяет через GPO (Group Policy Object) в домене Active Directory одной кнопкой развернуть и инвентаризацию, и средства удаленного доступа на все 100+ компьютеров организации.
